# aitop

> WorkBuddy Skill — `aitop`

## 简介

查询、搜索和展开 AITOP 的 AI 行业动态与每日精编日报。用于"今天 AI 圈发生了什么"、近期模型/产品/论文/行业动态、指定关键词搜索、AITOP 日报、资讯详情、来源核对和原文引用等请求。

## 安装

```bash
git clone https://github.com/funewa/aitop.git
cp -r aitop ~/.workbuddy/skills/aitop
```

## 使用

在 WorkBuddy 中直接描述你的需求，Agent 会依据 `SKILL.md` 的 `description` 自动匹配本技能。详见 `SKILL.md`。

## 目录结构

```
├── SKILL.md      # 技能定义（frontmatter + 说明）
├── scripts/
└── README.md
```
